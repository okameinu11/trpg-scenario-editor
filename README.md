# TRPGシナリオ執筆エディタ

エモクロアTRPG向けのシナリオ執筆エディタ。シナリオ本文・技能判定・共鳴判定・NPCデータを
ひとつの画面で書き、そのままPDFに出力できる。Androidタブレットでの執筆を想定している。

**`index.html` 1枚で完結する。** ビルド工程も依存パッケージもサーバーも無い。

## 使い方

ブラウザで `index.html` を開くだけで動く。ファイルをダブルクリックしても、
Webサーバー経由でも動作する。

```bash
# ローカルサーバー経由で開く場合（file:// と挙動が異なる箇所の確認用）
python -m http.server 8000
# → http://localhost:8000/ を開く
```

## データの保存について

**データはブラウザの localStorage にのみ保存される。** サーバーには何も送らない。

| | |
|---|---|
| 自動保存 | 入力のたびに「編集中の作業状態」を保存する。ブラウザを閉じても続きから再開できる |
| 手動保存 | 「💾 保存」（Ctrl+S）を押したものだけがシナリオ一覧に載る |

この2つは別物である。**自動保存されていてもシナリオ一覧には現れない。**

### 別の端末で使う・バックアップを取る

localStorage は端末・ブラウザごとに独立しているため、同じURLを開いても別の端末では
別のデータが見える。持ち運ぶには、シナリオ一覧から JSON ファイルを書き出す。

1. 📂 一覧 を開く
2. 「⬇ 全データを書き出し」で JSON ファイルを保存する（1シナリオずつの書き出しも可）
3. 移動先の端末で同じ画面を開き、「⬆ 読み込み」でそのファイルを選ぶ

読み込みは**マージ**で行う。既存のシナリオは残り、IDが一致するものだけが上書きされる。

> **注意**
> ブラウザのサイトデータを消すと保存内容も消える。定期的に書き出しておくこと。
> また NPC のアバター画像は画像そのものを保存領域に持つため容量を大きく消費する。
> 上限（おおむね 5MB）に達すると保存できなくなり、その旨が表示される。

## 開発

### clone した直後にやること

コミット時のチェック（pre-commit フック）はローカル設定のため clone には付いてこない。
有効にするには以下を実行する。

```bash
git config core.hooksPath .githooks
```

これで `git commit` のたびに `scripts/devenv/check-doc-sync.pl` が走り、
ドキュメントの更新漏れを検知する。実行に必要なのは git と Perl だけで、Node・npm は要らない
（Perl は Git for Windows に同梱されている）。

### 開発環境の構成

```bash
perl scripts/devenv/check-doc-sync.pl            # コミットゲートを手動実行
perl scripts/devenv/check-doc-sync.pl --summary  # 有効なルール一覧を表示
perl scripts/devenv/setup.pl --version           # devenv の版
cat scripts/devenv/UPDATES.md                    # 導入・変更の記録と、その理由
```

ルールの追加・変更は `devenv.config.json` を編集する（スクリプトは触らない）。
詳細は [`CLAUDE.md`](CLAUDE.md) の「コミット時のチェック」を参照。

### 構成

- `index.html` — アプリ本体。HTML・CSS・JavaScript が全て入っている
- `Code.gs` — Google Apps Script 版の旧バックエンド。**現在は使っていない**（2026-08-31 に撤去）
- `docs/` — このプロジェクトの仕様書。HTMLで持つ
- `scripts/devenv/`, `.githooks/`, `.claude/` — 開発環境基盤

データ永続化は `index.html` 内の `API` オブジェクトに集約されている。
保存先を変えるときはここだけを差し替える。UI側は保存先を知らない。
