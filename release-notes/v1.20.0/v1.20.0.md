# v1.20.0 (2026-10-16)

## 新機能

- 文字を太字にできるようになりました。文字を選んで Ctrl+B を押すと太字になり、もう一度押すと元に戻ります。下部の「本文」タブの「𝐁 太字」からも使えます。本文には **太字** の形で入るので、直接書くこともできます。
- 本文の中にリンクを作れるようになりました。飛ばしたい先に「📍 目印」で目印を置き、「🔗 リンク」（Alt+K）で目印や見出しを選ぶと、プレビューで押すとそこへ飛ぶリンクが入ります。見出しを選べば、その見出しに目印も自動で付きます。どちらも下部の「構成」タブにあります。本文には {#目印} と [表示](#目印) の形で入るので、直接書くこともできます。
- リンクの上で「🔗 リンク」を押すと、リンク先を選び直せます。目印の上で「📍 目印」を押すと目印の名前を変えられ、その目印へのリンクも一緒に書き換わります。
- リンク先の目印が見つからないときや、同じ名前の目印が2つあるときは、プレビューのリンクに波線が付きます（印刷には出ません）。リンクはPDF・HTML出力でも押して飛べます。
- 「🔍 探索一覧」（Alt+3）が、エリア名と場所を1行ずつ書く画面になりました。場所ごとにリンク先を選ぶと、一覧の項目が押して飛べるリンクになります。リンク先は「新しい小見出しを入れる」（一覧の後ろに、その場所の小見出しを作ります）・「リンクにしない」・本文の目印や見出しから選べます。
- プレビューの探索可能箇所の一覧をダブルクリックすると、同じ画面で場所やリンク先を直せます。
- 探索可能箇所の項目を押すと、その場所の小見出しへ飛びます。飛んだ先には「↑ 探索可能箇所へ」が出て、押すと一覧へ戻れます（印刷には出ず、HTML出力では押せます）。
- 技能判定・SANチェックに「条件:」で始まる行を書くと、いつその判定を出すかが、判定の見出しの下に帯で出ます。判定の画面の条件の欄に書いても入ります。
- プレビューの判定をダブルクリックすると、判定の画面が開いて中身を直せます。成功・失敗などの結果の文も、画面で書けるようになりました。

## 改善

- 判定で複数の技能を選んだときは「／」でつなぐようにしました（例: 目星／図書館）。以前の「または」でつないだ判定も「／」で表示されます。
- プレビューの最後に余白を空け、シナリオの最後の段落も画面の上の方で読めるようにしました。
- 情報・判定の結果・NPCのセリフ・探索可能箇所をコピーすると、目印は消え、リンクは表示の文字だけになります。

## 不具合修正

- 探索可能箇所の見出しを全角の「：」で書いたとき（[探索：書斎]）、エリア名が「このエリア」と表示されていたのを直しました。
