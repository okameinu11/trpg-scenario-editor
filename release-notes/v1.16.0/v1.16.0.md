# v1.16.0 (2026-10-10)

## 新機能

- 台本をHTMLファイルとして書き出せるようになりました。ヘッダーの「📤 出力」から「HTML出力」を選ぶと、プレビューと同じ見た目のファイルが1つでき、立ち絵やサムネイルも含めてそのファイルだけで開けます。PDFと違い、書き出したファイルでも情報と探索可能箇所の「📋 コピー」が使え、目次の項目から見出しへ移動できるので、配った台本からそのままチャットに貼れます。本文で使っているのに登録されていないNPCや情報があるときは、書き出す前にお知らせします。
- 場面図で、カードを格子に合わせて置けるようになりました。ツールバーの「▦ グリッド」が入のあいだ、動かしたカードが20pxの格子にそろうので、カードの縁を揃えやすくなります。押すたびに入り切りが切り替わり、設定は次に開いたときも引き継がれます。
- 場面図の線を、曲線と直角に曲がる線から選べるようになりました。ツールバーの「線」で切り替えます。シナリオごとに保存され、本文の [場面図]（プレビュー・PDF・HTML）にも同じ線で出ます。直角の線は、合流や分岐で線が重なって1本に見えないよう、線ごとに通る位置を少しずつずらして描きます。

## 改善

- ヘッダーの「🖨 PDF出力」ボタンを「📤 出力」にしました。押すと「PDF出力」と「HTML出力」を選べます。

## 不具合修正

- 場面図のカードで、「図解に出さない」「⚠ 未執筆」などのタグがカードの端からはみ出して切れていた問題を直しました。入りきらないときは2行目に回り、それでも収まらないカードだけ題名を1行に詰めます（切れた題名は、カードにマウスを乗せると全文が出ます）。あわせてカードを少し高くしたため、本文の [場面図] も少し縦に長くなります。
