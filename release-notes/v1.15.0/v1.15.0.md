# v1.15.0 (2026-10-09)

## 新機能

- アプリの名前を「Kotro（コトロ）」にしました。画面の左上とブラウザのタブに表示されます（画面の幅が狭いときは、左上の表示を省きます）。
- 本文とプレビューを並べて表示しているとき、どちらかをスクロールすると、もう片方も同じ場所まで動くようになりました。書いている所と仕上がりを、左右で見比べながら進められます。境目の鎖のボタン、または「すべての操作」（Ctrl+K）の「スクロールの連動」で、入り切りを切り替えられます。
- 探索可能箇所の一覧にもコピーボタンが付きました。「【探索可能箇所：エリア名】」と項目の一覧がコピーされるので、そのままチャットに貼れます。

## 改善

- 保存したシナリオの一覧を開くボタンを、左上の「📂 シナリオ一覧」ボタンにしました。以前の「📂 一覧」はボタンに見えにくかったため、ほかのボタンと同じ形にしています。
