# v1.19.0 (2026-10-15)

## 新機能

- 文字にルビ（ふりがな）を付けられるようになりました。文字を選んで下部の「本文」タブの「ふ ルビ」（Alt+R）を押し、読みを打って Enter を押すと、選んだ文字の上に読みが出ます。画面には仕上がりの見本が出ます。本文には {漢字|かんじ} の形で入るので、直接書くこともできます。
- ルビの付いた文字の上で「ふ ルビ」を押すと、そのルビを直したり外したりできます。
- 読みを文字数ぶん | で区切ると、1字ずつのルビになります（例: {漢字|かん|じ}）。
- ルビは見出し・本文・判定の結果・NPCのセリフ・表のセルなど、文字色を使える場所で使えます。色の中にも書けます（例: {赤:{黒川|くろかわ}}）。目次・印刷・PDF・HTML出力にもそのまま出ます。
- 判定の結果・NPCのセリフ・情報・探索可能箇所をコピーすると、ルビは「漢字（かんじ）」の形でチャットに貼れます。
