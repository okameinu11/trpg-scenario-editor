# v1.13.0 (2026-10-06)

## 新機能

- Ctrl+Z で操作を元に戻し、Ctrl+Y（または Ctrl+Shift+Z）でやり直せるようになりました。本文の入力欄の中では打った文字を細かく戻し、入力欄の外で押すと、NPC・情報・基本情報・巻末・場面図・タイトルを含めたシナリオ全体を操作の順に戻します。削除・並べ替え・場面カードの移動も戻せます。コマンドパレットの「元に戻す」「やり直す」からも使えます。

## 不具合修正

- 下部のボタンなどで記法を入れたあと、Ctrl+Z で戻せなくなり、それより前に打った文字も戻せなくなっていた問題を直しました。
- 空行をはさんで書いたTIPS（>>）が本文の横に並ばず、単独の行になっていた問題を直しました。直前の本文の右に並びます。
