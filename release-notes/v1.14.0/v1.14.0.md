# v1.14.0 (2026-10-07)

## 新機能

- 本文とプレビューの境目をドラッグして、幅を変えられるようになりました。境目のボタン（◀ ▶）や Alt+P で、プレビューだけ・本文だけを画面いっぱいに表示することもできます（もう一度押すと並べた表示に戻ります）。表示の状態は、次に開いたときも引き継がれます。
- プレビューの文章をダブルクリックすると、本文のその位置へ移動するようになりました。NPCカード・情報・表紙・FAQ・あとがきなどをダブルクリックすると、それを書いた画面が開きます。
- プレビューだけを表示しているときは、ダブルクリックした段落の原文がその場に開き、そのまま書き換えられます。Ctrl+Enter で確定、Esc で取り消しです。下部のボタンで入れる記法も、開いている欄に入ります。
