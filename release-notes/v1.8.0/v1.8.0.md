# v1.8.0 (2026-09-08)

## 新機能

- 画面上部に「場面図」タブを追加しました。場面をカードにして、分岐や合流を樹形図で並べられます。物語の骨格を目で追いながら書けます。
- 本文に書いた `#` の見出しを場面図へ取り込めます。カードをクリックすると、本文のその見出しへ飛びます。まだ書いていない場面をカードだけ先に置くこともでき、その場合は「未執筆」の印が付きます。
- 場面どうしをつないで、分岐と合流を表せます。カードを Ctrl を押しながら相手へドラッグするだけでつながります。引いている間に、つながるかどうかと、つながらない場合はその理由が出ます。つなぎ目には「【目星】成功」のような条件を書けます。話が輪になってしまう接続は作れないようにしてあります。
- 線がつながる辺は、カードの位置関係に合わせて変わります。上下に並べれば下と上、横に並べれば右と左で結ばれるので、カードを並べ替えても線が回り込みません。
- カードには概要メモ・種別（導入／調査／戦闘など）・登場NPCを持たせられます。種別はカードの色に出ます。
- カードは自由に動かせます。動かした位置は保存され、「整列」で自動配置に戻せます。
- 本文に `[場面図]` と書くと、場面のつながりがプレビューとPDFに図として出ます。`[場面図:書斎]` のように書くと、その場面から先だけを切り出せます。カードごとに図へ出すかどうかも選べます。

## 改善

- `#` で書いたのに、前に空行が無いせいで見出しになっていない行を、場面図タブで知らせるようにしました。これまではプレビューに出ないだけで、気づく手がかりがありませんでした。
