# v1.9.0 (2026-10-05)

## 新機能

- 台本に「プレイヤーへ渡す情報」を載せられるようになりました。日記や手紙など、セッション中にプレイヤーへ渡す情報を情報一覧に登録し、本文には `[情報:題名]` と書いて呼び出します。情報ごとのコピーボタンを押すと、「【題名】」と本文がコピーされるので、そのままチャットに貼れます。
- 情報ごとに公開対象（全員・HO1・目星成功者など）を決められ、色分けしたバッジで表示されます。新しく作った情報は「未設定」から始まるので、送り先の決め忘れに気づけます。
- 情報一覧（Alt+L、またはプレビュー上部の「情報一覧」）で、情報の追加・編集・コピーができます。情報は本文で使っている場面ごとにまとまり、題名を押すと台本のその位置へ移動します。情報の題名を変えると、本文の呼び出しも自動で書き換わります。
- NPCのセリフを書く記法 `[セリフ:NPC名]` を追加しました。NPCのアイコンと名前が付き、NPCごとに決めた色で表示されます。`[セリフ:NPC名/震える声で]` のように、読み上げ方などの備考も添えられます。
- 下部の「NPCのセリフ」（Alt+Q）と「情報」（Alt+I）から、一覧で選んで本文に挿入できます。
- Ctrl+K で、すべての操作を名前で探して実行できる画面を開けるようになりました。各操作のショートカットキーも一緒に表示されるので、使ううちに覚えられます。
- NPCのメモを、題名を付けて複数書けるようになりました。これまでのメモは「設定メモ」という題名で引き継がれます。

## 改善

- 下部の挿入ボタンを種類ごとにまとめ直し、横にスクロールしなくても全部のボタンが見えるようにしました。ショートカットキーは、ボタンにマウスを乗せると表示されます。
- NPC管理を「基本・能力値・技能・共鳴感情・メモ」のタブに分けました。NPC一覧も、画面の下端まで表示されるようになりました。
- 所持技能を、名前と値が揃った一覧で見やすくしました。技能名と値は別の欄で入力でき、値を空けたまま追加すると、エモクロアは Lv1、クトゥルフ神話TRPGは技能の初期値が入ります。
- サイドに表示される小さなNPCカードは、場面ごとに、そのNPCが最初に話すところでだけ表示するようにしました。

## 不具合修正

- ショートカットキーを設定したときのお知らせに「null」と表示されていた問題を直しました。
- クトゥルフ神話TRPGのシナリオで Alt+7 を押すと、共鳴判定の画面が開いていた問題を直しました。
- 名前に「&」を含むNPCのカードが「未登録」と表示されていた問題を直しました。
