# v1.12.0 (2026-10-05)

## 新機能

- 本文に [目次] と書くと、その場所に目次が自動で入るようになりました。シーン見出しと探索小見出し、巻末のFAQやあとがきの見出しが並び、項目を押すとその見出しへ移動します。PDFでも目次の項目から見出しへ移動できます。
- 文字色とNPCのセリフの色で、よく使う色を「マイパレット」に登録しておけるようになりました。登録した色は、どちらの画面でも1回押すだけで選べます。
- シナリオ基本情報の見出しの中に、「プレイ人数」「想定時間」のような小見出しと内容を置けるようになりました。また、見出しや小見出しの構成に名前を付けてテンプレートとして保存し、別のシナリオで呼び出せるようになりました。
