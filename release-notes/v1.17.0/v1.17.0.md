# v1.17.0 (2026-10-14)

## 新機能

- 表を書けるようになりました。本文に [表:題名] と書き、次の行から「| 見出し | 見出し |」のように1行に表の1行を書くと、罫線の表になります（1行目が見出しの行です）。ほかで書いた Markdown の表を [表:題名] の次の行に貼っても、そのまま表になります。下部の「🗺 場面図・目次・表」（画面の幅が狭いときは「図・目次」）から「表を挿入」で入れられ、文字を選んでから押すと、選んだ行がそのまま表の行になります（表計算ソフトから貼った行も、セルに分かれます）。PDFでは、表の1行がページの途中で切れず、見出しの行は次のページの先頭にも出ます。
- 技能判定とSANチェックの結果をコピーできるようになりました。プレビューで「成功」「効果的成功」などのラベルを押すと、その結果の文がコピーされるので、そのままチャットに貼れます。HTML出力したファイルでも使えます。
- NPCのセリフに「📋 コピー」ボタンが付きました。名前の横のボタンを押すと、発言の文だけがコピーされます（名前と備考は付きません）。ボタンは印刷・PDFには出ず、HTML出力したファイルでは使えます。
