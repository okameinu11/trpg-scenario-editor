# v1.18.0 (2026-10-14)

## 新機能

- 表をマス目で作れるようになりました。下部の「本文」タブの「📊 表」を押すと表の編集画面が開き、セルに直接書いて表を作れます。Tab で右、Enter で下のセルへ移り、最後のセルから進むと行が増えます（セルの中の改行は Shift+Enter）。行・列の追加と削除、列の寄せ、セルの結合はボタンでできます。表計算ソフトでコピーした範囲を貼ると、セルに分かれて入ります。「決定（本文へ入れる）」を押すと本文に入り、Ctrl+Z を1回押せば入れる前に戻せます。
- 本文の表を、編集画面で直せるようになりました。プレビューの表をダブルクリックするか、本文の表の中にカーソルを置いて「📊 表」を押すと、その表が編集画面で開きます。
- 表で、列の寄せ・セルの中の改行・セルの結合・見出しの指定ができるようになりました。編集画面のボタンでできるほか、本文に直接書くこともできます。区切りの行（|---|）に :-: と書くと中央、-: と書くと右に寄せます。セルに <br> と書くと改行し、< だけを書くと左のセルと、^ だけを書くと上のセルとつながります（記号そのものを見せたいときは、全角の ＜ ＾ で書きます）。題名の後ろに /見出し列 と書くと1列目が見出しになり、/見出しなし と書くと見出しの行の無い表になります（例: [表:進行の目安/見出し列]）。

## 改善

- 下部のボタンを「構成」「本文」「判定」「資料」のタブに分けました。開いているタブのボタンだけが並ぶので、画面の幅が狭くても、ボタンの名前が省かれにくくなりました。開いていたタブは、次に開いたときも引き継がれます。
- 「🗺 場面図・目次・表」にまとめていた場面図と目次は、「構成」タブのそれぞれのボタンになりました。表は「本文」タブの「📊 表」から入れます。
